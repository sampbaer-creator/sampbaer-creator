## Featured Project

### [WattWeather](https://github.com/sampbaer-creator/WattWeather)

**Weather and electricity analytics people can actually understand**

WattWeather combines live city weather, public U.S. Energy Information Administration electricity statistics, and optional personal utility records. It includes interactive charts, temperature-versus-energy correlation, explainable forecasting, a private CSV workspace, and both web and cross-platform .NET implementations.
